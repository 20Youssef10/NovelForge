# NovelForge Quality Gate

Project-wide completion gate. Run the checks that apply; record evidence for every finding. A gate does not invent fixes — it records what is wrong, what can be safely repaired, and what needs the author.

## Checks
- [ ] Structure and narrative value — every unit changes something
- [ ] Causality — major turns earned, not convenient
- [ ] Consequences — downstream effects appear where they should
- [ ] Character agency — decisions follow from goals, beliefs, knowledge
- [ ] Character arc — change earned through choices, not exposition
- [ ] Dialogue and voice — distinct voices, subtext, no information dumping
- [ ] Narrative voice and POV — no head-hopping, no omniscient leakage
- [ ] Style DNA and style drift — consistent, deviations intentional
- [ ] Generic writing — prose specific to this book
- [ ] Cliché and trope intent — conventions functioning deliberately
- [ ] Continuity — no contradictions; knowledge states respected
- [ ] Timeline — chronology coherent, ages and durations consistent
- [ ] Canon — changes classified, approved, and migrated
- [ ] Narrative graph integrity — IDs intact, no orphans or dead edges
- [ ] Mystery and reader knowledge — fair clues, no accidental spoilers
- [ ] Foreshadowing and payoff debt — setups live, payoffs in window
- [ ] Pacing and tension — tempo serves function; stakes are real
- [ ] Theme and motif — emerging through choices and consequences
- [ ] Power and battle logic — rules respected, reversals caused
- [ ] Faction plausibility — partial information, internal disagreement
- [ ] Research provenance — load-bearing claims verified or marked uncertain
- [ ] Version and branch integrity — attributable, reversible, correct branch
