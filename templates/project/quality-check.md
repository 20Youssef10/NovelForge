# Quality Gate

Use for a single unit (scene, chapter, arc). Project-wide audits use `templates/QUALITY_GATE.md` instead. Run the checks that apply; a dialogue scene does not require a power audit.

## Checks

- [ ] Structure and narrative value (does this change something?)
- [ ] Causality (are turns earned, not convenient?)
- [ ] Consequences (do downstream effects appear where they should?)
- [ ] Character agency (decisions follow from goals, beliefs, knowledge?)
- [ ] Character arc (is change earned through choices?)
- [ ] Dialogue and character voice (distinct, subtext, no information dumping?)
- [ ] Narrative voice and POV (no head-hopping or leakage?)
- [ ] Style DNA and style drift (consistent, with deviations intentional?)
- [ ] Generic writing (prose specific to this book?)
- [ ] Cliché and trope intent (conventions functioning deliberately?)
- [ ] Continuity (no contradictions; knowledge states respected?)
- [ ] Timeline (chronology coherent?)
- [ ] Canon (changes classified and approved?)
- [ ] Narrative graph integrity (IDs intact, no orphaned edges?)
- [ ] Mystery and reader knowledge (fair clues, no accidental spoilers?)
- [ ] Foreshadowing and payoff debt (setups live, payoffs in window?)
- [ ] Pacing and tension (tempo serves function; stakes real?)
- [ ] Theme and motif integration (emerging through choices?)
- [ ] Power and battle logic (rules respected, reversals caused?)
- [ ] Faction plausibility (partial information, internal disagreement?)
- [ ] Research provenance (claims verified or marked uncertain?)
- [ ] Version and branch integrity (attributable, reversible, correct branch?)
