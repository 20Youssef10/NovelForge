# Character Arc Engine v2.1

An arc is a change in what a character believes, expressed through choices that cost them something. Transformation delivered by exposition is not an arc; it is a summary of one.

## Milestones

Track, for each significant character:

initial state → governing belief → wound or flaw → desire → pressure → key dilemmas → key choices → consequences → reversals → realisation → final state

The governing belief is the pivot. A character without a stated belief cannot change believably, and a change that does not revise something the character held is not development — it is a different character.

## The earning test

Ask what the character would lose by changing. If nothing, the change is costless and the arc will not register. Then ask whether each step in the arc followed from the previous one under pressure, or whether steps were inserted to reach a predetermined end.

The most reliable arcs are driven by repeated dilemmas where the character's established method fails. Each failure should make the next choice harder, not merely different.

## Audit

Detect:

- **Stagnation** — pressure without change across a whole arc.
- **Forced redemption** — a death, a speech, or a villain's kindness doing the work of earned change.
- **Unearned corruption** — betrayal without the beliefs and incentives that make it inevitable.
- **Repetitive lessons** — the same realisation delivered repeatedly.
- **Contradictory turning points** — reversals that contradict the character's established core.
- **Missing consequences** — significant choices with no effect on who the character becomes.
- **Telegraphed reversal** — a betrayal foreshadowed so heavily it costs nothing.

## Reversals

A reversal should be caused by the character's own method meeting its limit, not by external coincidence. Test whether the character could have prevented it by choosing differently; if not, it is a reversal in name only.

## Coordination

Use `character-development` for the underlying psychology, `character-simulation` to test each choice, `theme-engine` where the arc tests a thematic question, `consequence-engine` for what each choice costs, and `plot-engineering` for the external pressure that drives it.
