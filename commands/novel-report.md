Produce a full agent report.

1. Fill `templates/AGENT_REPORT.md`.
2. Cover work completed, files changed, graph and canon changes, branch and version changes, and every engine that ran with its result.
3. List safe automatic repairs separately from high-impact approval items.
4. Report unresolved risks plainly. Do not soften them to make the work look finished.
5. Include memory updates and the next workflow step.
6. If any engine did not run, say so rather than implying coverage.
