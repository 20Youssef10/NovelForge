Import an existing manuscript.

1. Load the `manuscript-import` skill and follow its phases in order.
2. Read the whole draft before writing anything. Inventory first, and report before touching project files.
3. Obtain approval between phases. Intake is a HIGH-risk structural operation.
4. Record every extraction in `import/EXTRACTION_LOG.md` with its source location.
5. Classify nothing as permanent canon until the author confirms it. Everything discovered starts `UNRESOLVED`.
6. Preserve the author's sentences exactly. Import maps structure; it never rewrites prose.
7. Finish with a `critique` run, because this is when structural problems first become visible.
