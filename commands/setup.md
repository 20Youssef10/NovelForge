Configure the project.

1. Load `project-settings`. Read `PROJECT_SETTINGS.md` before changing anything.
2. Change only the fields the author has decided. Every other field stays `UNRESOLVED`,
   which is a valid state and is never guessed.
3. For POV and tense, confirm the choice and note what it changes: the narrator's
   knowledge boundary, what the narration may know, and which head-hopping errors
   become available.
4. For approval strictness, record the reason in the change log. Strictness usually
   changes because something nearly went wrong, and the reason is the useful part.
5. Remind the author that HIGH-risk work always requires approval, at every strictness
   level. `permissive` relaxes only MEDIUM.
6. Never set a field to make a validation pass. Unresolved is a valid answer.
7. A setting never overrides canon or a current instruction from the author.
