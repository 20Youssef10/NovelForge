# Generic-Writing Pattern Reference

Detailed catalogue for `generic-writing-detector`. Load when a passage is suspected of being styleless and the specific pattern needs identifying. The skill body carries the method; this file carries the inventory.

## What generic prose has in common

It could be moved into a different novel with only the names changed. That is the test. A sentence is generic when its content could have been generated without reference to this book, these characters, or this world.

That is different from being plain, short, simple, or polished. Understatement is a style. Simplicity is a style. Neither is a defect.

## Pattern catalogue

### Vague sensory filler
Sensory language that names a sensation without naming anything in the world.
- "the air was thick", "a chill ran down his spine", "the room felt heavy"
- Fix direction: replace with the specific thing the character is actually attending to. A ledger they are not reading. A smell they associate with someone.

### Stock emotional labels
Abstract feeling-names substituting for a choice that would have produced the feeling.
- "she felt a pang of guilt", "he was overcome with sadness", "a wave of emotion"
- Fix direction: show the decision or omission that caused it. The label is a report about the prose, not an experience.

### Empty intensity
Dramatic emphasis with no content behind it.
- "it was nothing short of devastating", "truly remarkable", "unforgettable"
- Fix direction: delete and see whether anything is lost. Usually not.

### Formulaic transitions
Filler that signals narrative movement without providing it.
- "little did he know", "in that moment, everything changed", "and so it began", "the air was thick with tension"
- Fix direction: cut. The transition is almost always doing work the next paragraph should do.

### Repeated cadence
The same sentence shape and rhythm sustained across a stretch, producing a lulling effect.
- Fix direction: vary only where meaning changes. Uniform rhythm is a defect; deliberate uniformity is a motif and should be in the motif register.

### Interchangeable metaphor
Images from a general storehouse rather than from this world.
- Test: could this image belong to a novel in a different genre, decade, and setting? If yes, it is borrowed.
- Fix direction: source images from the world's own materials, the character's trade, or their memory.

### Low-specificity narration
Description that would fit any room, city, or weather.
- Test: swap the setting noun. Does the sentence break? If not, it is not describing anything.
- Fix direction: choose two or three details that could only occur here.

### Over-explanation
Narration stating the meaning of what has just been shown.
- Fix direction: delete the explanatory sentence. If the scene does not carry the meaning, fix the scene, not the gloss.

### Exposition substituting for scene
History, rules, or motivation delivered as summary because dramatising them would take space.
- Fix direction: find the character who needs this information now and let the scene deliver it under pressure.

### Genre-default phrasing
Phrasing that belongs to the genre's average rather than to this book.
- Test: is this how a character in this book would phrase it, or how an average book of this genre would?
- Fix direction: revoice, or accept deliberately if the average phrasing is doing characterisation work.

### Signposted meaning
Characters and narration announcing subtext the text has already delivered.
- "He didn't realise, but she did", "Little did he know, he was already in danger"
- Fix direction: trust the reader once. Remove the announcement.

## Precision tests worth running

1. **Swap test** — replace the setting noun. If the sentence survives, it describes nothing.
2. **Voice test** — would this character phrase it this way?
3. **Deletion test** — remove the sentence. If the scene is unchanged, it was generic.
4. **Attribution test** — could this be written by an author who has not read the book? If yes, it is generic.

## What to preserve

- Intentional stylistic repetition, refrains, and recurring cadence
- Understatement and plainness used as deliberate register
- A character's distinctive phrasing, which is voice rather than filler
- Genre conventions, which `anti-cliche` assesses rather than this skill
