# Symbolism and Motif Engine v2.1

Track the elements that recur and what they come to mean. A motif earns its place by changing; an image that appears five times with identical significance is decoration, not design.

## Model

Assign stable IDs to meaningful motifs and record in `themes/MOTIF.md`:

- the element
- first appearance and where it enters
- contextual meaning at each appearance
- transformations across appearances
- associations
- counter-symbols — elements deliberately set against it
- thematic links
- payoff or closure
- status

## Design

A motif should accrue meaning through use. Establish it plainly first, so its first appearance is not conspicuous, then let its significance shift as the context changes — the same object in a different emotional register means something new.

Distinguish a **motif** (a recurring element with accumulating meaning) from a **symbol** (a single element standing for an abstraction) and a **callback** (a deliberate reference to an earlier moment). They serve different functions and fail differently.

## Detection

- **Decorative repetition** — recurrence with no evolution.
- **Accidental symbolism** — a pattern implied by frequency that the author did not intend and has not accounted for.
- **Over-explanation** — narration or dialogue naming what the image already conveyed. Once a motif is interpreted aloud it stops functioning.
- **Inconsistent meaning** — the same element used for contradictory purposes without a transformation to justify it.
- **Premature accumulation** — too many motifs introduced before any has been transformed.
- **Abandoned motif** — established and never returned to.

## Payoff

Return to motifs at the moments that matter, and let the return carry more than the original. A motif that resolves its own meaning has been a symbol; a motif that transforms is doing narrative work.

Not every motif needs resolution. A recurring detail can simply be true to the world. Reserve interpretation for elements that are genuinely doing work.

## Rules

Coordinate meaning with the theme; a motif that supports a theme nobody asked for is noise. Do not add motifs to strengthen a thin theme — build events instead. Keep the count manageable: a novel with forty tracked motifs has a tracking problem, not a richness problem.

## Coordination

Use `theme-engine` for what motifs serve, `narrative-style` for the figurative register, `foreshadowing` for motifs that plant, and `payoff-debt` to register motif returns as obligations.
