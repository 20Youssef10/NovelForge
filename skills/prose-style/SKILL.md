# Prose-Style (deprecated alias)

This skill has been merged into `narrative-style`, which owns Style DNA construction, the prose contract, style-preserving revision, and comparison of candidate passages against the novel's established voice. POV, focalisation, and reliability remain with `narrative-voice`.

**Route all style work to `narrative-style`.**

Kept in place so that existing projects, prompts, and command references that invoke `prose-style` continue to resolve rather than failing. It carries no independent behaviour; the records in `style/` are shared.

The governing rule is unchanged: apply the novel's own Style DNA, and never genericise or flatten the author's voice to achieve consistency.
